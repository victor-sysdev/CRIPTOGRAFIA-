# 🔐 Projeto de Criptografia em Python

## 📌 Descrição
Projeto simples para estudar criptografia simétrica em Python, utilizando a biblioteca cryptography com a classe Fernet.

---

## 🔑 Criptografia Simétrica
Usa uma única chave para criptografar e descriptografar dados.

Vantagens:
- Rápida  
- Eficiente  

Desvantagem:
- Depende do sigilo da chave  

---

## 🧰 Biblioteca: cryptography (Fernet)
O Fernet fornece criptografia segura pronta para uso.

Recursos:
- Baseado em criptografia simétrica (AES)  
- Garante integridade dos dados  
- Simples de implementar  

---

## ⚙️ Como funciona
1. Usuário digita uma mensagem  
2. Uma chave é gerada  
3. A mensagem é criptografada  
4. Pode ser descriptografada com a mesma chave
